Mathematical background and further reading

The computational ideas in this guide build on standard orthogonal factorizations and their modification after changes to a matrix. For full treatments, see Golub and Van Loan (2013) and Björck (2015); for least-squares algorithms, see Björck (2024). The package authors develop updating methods and statistical applications in Bernardi, Busatto, and Cattelan (2024).

1 Why orthogonal transformations?

Multiplication by a square orthogonal matrix preserves the Euclidean norm. If \(X=Q_1R_1\) and \(Q=[Q_1,Q_2]\) is a full orthogonal completion, then \[ \|y-Xb\|_2^2 =\|Q_1^\top y-R_1b\|_2^2+\|Q_2^\top y\|_2^2. \] The second term does not depend on \(b\). For a full-rank design, the least-squares solution is obtained by solving \(R_1\widehat\beta=Q_1^\top y\). This avoids explicitly inverting a matrix.

2 Classical and modified Gram–Schmidt

Let \(X=[x_1,\ldots,x_p]\in\mathbb R^{n\times p}\) have linearly independent columns, with \(n\geq p\). Classical Gram–Schmidt constructs an orthonormal basis for their span. At step \(k\), set \[ \begin{aligned} r_{jk}&=q_j^\top x_k\quad(j<k),\\ v_k&=x_k-\sum_{j=1}^{k-1}r_{jk}q_j,\\ r_{kk}&=\|v_k\|_2,\qquad q_k=v_k/r_{kk}. \end{aligned} \] The empty sum at \(k=1\) is zero. Full column rank ensures \(r_{kk}>0\) in exact arithmetic. With \(r_{jk}=0\) for \(j>k\), these identities give \(X=QR\) and \(Q^\top Q=I_p\). The temporary residual \(v_k\) is distinct from the normalized vector \(q_k\).

Modified Gram–Schmidt instead starts with \(v=x_k\) and, for \(j=1,\ldots,k-1\), successively computes \[ r_{jk}=q_j^\top v,\qquad v\leftarrow v-r_{jk}q_j; \] it then sets \(r_{kk}=\|v\|_2\) and \(q_k=v/r_{kk}\). The two algorithms are equivalent in exact arithmetic, but their floating-point behavior differs: computing projections from the updated residual generally reduces loss of orthogonality. Reorthogonalization may still be needed for difficult problems (Golub and Van Loan 2013; Björck 2015).

The following educational implementation checks both defining identities on a well-conditioned example; it is not a replacement for the package’s factorization routines.

mgs <- function(X) {
  n <- nrow(X); p <- ncol(X)
  Q <- matrix(0, n, p); R <- matrix(0, p, p)
  for (k in seq_len(p)) {
    v <- X[, k]
    if (k > 1L) for (j in seq_len(k - 1L)) {
      R[j, k] <- sum(Q[, j] * v)
      v <- v - R[j, k] * Q[, j]
    }
    R[k, k] <- sqrt(sum(v^2))
    if (R[k, k] <= .Machine$double.eps * sqrt(sum(X[, k]^2)))
      stop("Numerically dependent column: use a rank-revealing factorization.")
    Q[, k] <- v / R[k, k]
  }
  list(Q = Q, R = R)
}
set.seed(2040)
X_gs <- matrix(rnorm(80 * 8), 80, 8)
gs <- mgs(X_gs)
gs_checks <- c(reconstruction = norm(X_gs - gs$Q %*% gs$R, "F") / norm(X_gs, "F"),
               orthogonality = norm(crossprod(gs$Q) - diag(8), "F"))
gs_checks
## reconstruction  orthogonality 
##   1.154784e-16   1.019128e-15
stopifnot(max(gs_checks) < 1e-10)

3 Householder transformations and Givens rotations

A Householder reflector has the form \[ H=I-2vv^\top/(v^\top v),\qquad v\ne0. \] It is symmetric and orthogonal and can eliminate all entries below a selected diagonal entry in a column. A sequence of reflectors produces an upper triangular factor. Compact storage keeps the information defining these reflectors instead of storing every entry of \(Q\).

A Givens rotation acts on two coordinates through the block \[ \begin{pmatrix}c&s\\-s&c\end{pmatrix},\qquad c^2+s^2=1. \] Choosing \(c=a/\sqrt{a^2+b^2}\) and \(s=b/\sqrt{a^2+b^2}\) maps \((a,b)^\top\) to \((\sqrt{a^2+b^2},0)^\top\) when \((a,b)\ne(0,0)\). Rotations can restore triangular structure after localized changes. Both algorithms exploit orthogonal transformations; neither makes an ill-conditioned statistical problem intrinsically well conditioned.

4 What a row update changes

Write a batch of new observations as \(U^\top\), with \(U\in\mathbb R^{p\times m}\). Starting with \(X=Q_1R_1\), a triangular factor for the enlarged design can be obtained by triangularizing \[ \begin{pmatrix}R_1\\U^\top\end{pmatrix}. \] The stacked matrix has \(p+m\) rows and \(p\) columns: \(R_1\) is \(p\times p\) and \(U^\top\) is \(m\times p\). Its Gram matrix is \(R_1^\top R_1+UU^\top=X_{\mathrm{new}}^\top X_{\mathrm{new}}\). This explains why the previous triangular factor contains useful information for a row update.

Deleting rows changes the plus sign to a minus sign. A valid downdate requires the remaining design to retain the rank needed by the subsequent solve. The algebraic relation alone does not guarantee favorable conditioning after deletion.

5 Ridge as augmented least squares

For the normalized ridge criterion used in the regression chapter, define the augmented response and design by \[ \widetilde y=\begin{pmatrix}y\\0_p\end{pmatrix}\in\mathbb R^{n+p},\qquad \widetilde X=\begin{pmatrix}X\\\sqrt{n\lambda}I_p\end{pmatrix} \in\mathbb R^{(n+p)\times p}. \] The \(p\) additional entries of \(\widetilde y\) are zero, and the \(p\) additional rows of \(\widetilde X\) encode the penalty. For \(b\in\mathbb R^p\),

\[ \begin{aligned} \|\widetilde y-\widetilde Xb\|_2^2 &=\left\|\begin{pmatrix}y-Xb\\-\sqrt{n\lambda}b\end{pmatrix}\right\|_2^2\\ &=\|y-Xb\|_2^2+n\lambda\|b\|_2^2. \end{aligned} \] The augmented formulation is useful as an independent QR reference. It also makes the factor \(n\) explicit: changing the normalization of the loss changes the interpretation of \(\lambda\).

The intercept is handled separately in the ridge tutorial by centering. If a column of ones were simply included in the penalized design, that coefficient would also be penalized. Predictor means and scales must be estimated again within each cross-validation training fold.

6 Choosing a representation

Use compact factors when storage is important and \(Q\) need not be explicitly formed. Use thin factors when orthogonal projections or direct QR solves are needed. Use full factors when an operation requires an orthogonal completion, as in the QR update examples here. An R-only representation is attractive when Gram information and triangular solves suffice, but auxiliary quantities such as \(X^\top y\) still need to be maintained for regression.

The worked examples demonstrate these distinctions through reconstruction identities, independent solutions and measured timings. They should be read together with the function documentation for the installed package version.
